Evidence Rules
Raw transcripts should remain preserved as source evidence.
Reports must distinguish observed facts, claims, marketing, speculation, inference, and project-specific interpretation.
A reference report is not automatically canonical doctrine.
Important claims should be verified before operational use.
Secrets, credentials, and private customer information must never be committed.
Adding a New Topic

Create matching topic folders under:

transcripts/<topic>/
reports/<topic>/

Store any reusable generation prompt under:

prompts/

Use clear file names and include source metadata whenever possible.
